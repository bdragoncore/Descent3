PART 2: TEST DATA GENERATION STRATEGY
================================================================================

APPROACH: Hybrid (Static Fixtures + Seeded Random)
----------------------------------------------------
- Static fixtures: Pre-defined valid test cases (edge cases, known inputs)
- Seeded random: Deterministic random data with fixed seeds for reproducibility

PREDICTABILITY: Seeded RNG
----------------------------------------------------
- Each test class uses a fixed seed (e.g., srand(12345))
- Seeds logged at test start for reproduction: "Seed: 12345"
- Failures include seed in error output for debugging
- Option to replay with --seed=12345

GENERATOR TYPES (Per-Type)
----------------------------------------------------
1. Math Generators (vecmat/)
   - Vector2D, Vector3D: random within bounds (-1000 to 1000)
   - Matrix: random rotation/scale matrices
   - Angles: random 0-360 degrees
   - Quaternion: normalized random quaternions

2. Physics Generators (physics/)
   - PhysicsState: random velocity, acceleration, mass
   - CollisionSphere: random radius 0.1 to 10.0
   - RaySegment: random start/end points
   - FVIQuery: random query parameters

3. Object Generators (Descent3/)
   - Object: random type (robot, weapon, player, powerup)
   - ObjectHandle: valid/invalid handles
   - Room: minimal room with faces/portals
   - Polygon: random vertices within bounds

4. Game State Generators
   - Player: random health, shields, energy
   - Weapon: random weapon type, ammo
   - AIState: random awareness, goals
   - Inventory: random items, counts

5. World Generators
   - Level: minimal level with rooms, objects
   - Terrain: random heightmap (simplex noise)
   - Trigger: random type, effects

VALIDITY RULES (Data must be valid for the game)
----------------------------------------------------
- Vectors: no NaN, no Inf
- Object positions: within world bounds (-10000 to 10000)
- Room indices: valid range
- Physics: mass > 0, radius > 0
- Health/shields: 0-1000

EDGE CASES (Static fixtures)
----------------------------------------------------
- Zero vectors, identity matrices
- Boundary values (min/max)
- Empty containers
- Invalid handles
- NaN, Inf in math tests

GENERATOR INTERFACE EXAMPLE
----------------------------------------------------
class VectorGenerator {
    uint32_t seed_ = 12345;
    std::mt19937 rng_;
    
public:
    Vector3D random(float min=-1000, float max=1000);
    Vector3D zero();
    Vector3D boundary();
};

class ObjectGenerator {
    VectorGenerator vgen_;
    Object random(ObjectType type);
    Object valid_player();
    Object valid_robot();
};
