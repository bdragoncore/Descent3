  pkg-config --exists gl  && echo "GL OK"  || echo "GL MISSING"

  On Arch, llvmpipe driver path:

STEP 2 - AUDIT THE RENDERER BEFORE TOUCHING ANYTHING
================================================================================

The renderer was refactored after the original 1.5 release into multiple files.
SDL context creation and SwapBuffers may NOT be in HardwareOpenGL.cpp.
You MUST read these three files before writing any MesaOpenGL.cpp code.

  cat renderer/HardwareOpenGL.cpp  | grep -n "SDL_GL\|SDL_Create\|SDL_Destroy"
  cat renderer/HardwareSetup.cpp   | grep -n "SDL_GL\|SDL_Create\|SDL_Destroy"
  cat renderer/HardwareBaseGPU.cpp | grep -n "SDL_GL\|SDL_Create\|SDL_Destroy"

Goal: find which file contains:
  - SDL_GL_CreateContext  (or SDL_GL_CreateContextWithProperties in SDL3)
  - SDL_CreateWindow
  - SDL_GL_MakeCurrent
  - SDL_GL_SwapWindow
  - SDL_GL_DestroyContext  (NOTE: SDL3 uses DestroyContext, NOT DeleteContext)
  - SDL_DestroyWindow

ALSO verify the rend_Init signature:

  grep -n "rend_Init" lib/renderer.h Descent3/init.cpp renderer/*.cpp

ALSO verify g3_Init exists as a standalone call:

  grep -rn "g3_Init\b" 3d/ Descent3/

ALSO verify cfile init function name:

  grep -n "^bool\|^void\|^int" cfile/cfile.h | grep -i init

Write down your findings. The MesaOpenGL.cpp plan depends on them.

STEP 6 - CREATE MesaOpenGL.cpp
================================================================================

Using your findings from Step 2, identify which file contains SDL context init.
That file is your clone source. It may be HardwareSetup.cpp, not HardwareOpenGL.cpp.

  # Example - adjust source file based on Step 2 findings:
  cp renderer/HardwareSetup.cpp renderer/MesaOpenGL.cpp

Changes to make in MesaOpenGL.cpp (and ONLY these changes):

  A. Replace SDL includes at the top:

     REMOVE:
       #include <SDL3/SDL.h>
       #include <SDL3/SDL_opengl.h>

     ADD:
       #include <EGL/egl.h>
       #include <EGL/eglext.h>
       #include <GL/gl.h>
       #include <GL/glext.h>

  B. Replace SDL window/context globals with EGL globals:

     REMOVE:
       static SDL_Window*   gl_window  = nullptr;
       static SDL_GLContext  gl_context = nullptr;

     ADD:
       static EGLDisplay  mesa_display = EGL_NO_DISPLAY;
       static EGLSurface  mesa_surface = EGL_NO_SURFACE;
       static EGLContext  mesa_context = EGL_NO_CONTEXT;

  C. Replace the renderer init body (SDL window creation section only):

     The new init body sets llvmpipe env vars, then calls:
       eglGetPlatformDisplayEXT  (prefer) or eglGetDisplay (fallback)
       eglInitialize
       eglBindAPI(EGL_OPENGL_API)
       eglChooseConfig  with EGL_PBUFFER_BIT | EGL_OPENGL_BIT
       eglCreatePbufferSurface  with width/height
       eglCreateContext  requesting OpenGL 3.3 core
       eglMakeCurrent

     Everything after that (glViewport, glEnable, state setup) is UNCHANGED.

     llvmpipe env vars to set at top of init:
       setenv("GALLIUM_DRIVER",             "llvmpipe", 1);
       setenv("LIBGL_ALWAYS_SOFTWARE",      "1",        1);
       setenv("MESA_GL_VERSION_OVERRIDE",   "3.3",      1);
       setenv("MESA_GLSL_VERSION_OVERRIDE", "330",      1);

  D. Replace SwapBuffers:

     REMOVE the SDL_GL_SwapWindow call.
     REPLACE with a no-op comment:
       // No-op: framebuffer read via glReadPixels

  E. Replace shutdown:

     REMOVE SDL_GL_DestroyContext and SDL_DestroyWindow calls.
     REPLACE with:
       eglMakeCurrent(mesa_display, EGL_NO_SURFACE,
                      EGL_NO_SURFACE, EGL_NO_CONTEXT);
       eglDestroyContext(mesa_display, mesa_context);
       eglDestroySurface(mesa_display, mesa_surface);
       eglTerminate(mesa_display);
       mesa_display = EGL_NO_DISPLAY;
       mesa_surface = EGL_NO_SURFACE;
       mesa_context = EGL_NO_CONTEXT;

  IMPORTANT - DO NOT CHANGE:
    - Any glBindTexture, glTexImage2D, glTexSubImage2D calls
    - Any glDrawArrays, glDrawElements, VAO/VBO setup
    - Any glEnable, glDisable, glBlendFunc calls
    - Any shader code, uniform uploads, attribute bindings
    - Any state caching or texture management code
    - Any glViewport, glScissor, glClear, glClearColor calls
    - Any glMatrixMode, glLoadIdentity, glOrtho calls (if still present)

  else()

          HardwareOpenGL.cpp   # or HardwareSetup.cpp - whichever owns SDL init

================================================================================
STEP 13 - TROUBLESHOOTING
================================================================================

PROBLEM: "EGL MISSING" from pkg-config
FIX:     On Ubuntu: sudo apt install libegl-dev
         On Arch:   sudo pacman -S mesa

PROBLEM: "no EGL display" at runtime
FIX:     Verify GALLIUM_DRIVER=llvmpipe and LIBGL_ALWAYS_SOFTWARE=1 are set.
         Check that llvmpipe_dri.so exists (see Step 1 VERIFY).

PROBLEM: eglCreateContext returns EGL_NO_CONTEXT
FIX:     Mesa on some distros only supports OpenGL 3.1 via llvmpipe by default.
         The MESA_GL_VERSION_OVERRIDE=3.3 env var should fix this.
         If not, try MESA_GL_VERSION_OVERRIDE=3.1 and adjust context attrs.

PROBLEM: "D3: lohud.fnt not found"
FIX:     Confirm d3.hog is at $HOME/Descent3/d3.hog or set D3_PATH.
         Confirm d3.hog is a valid Descent 3 HOG archive (not renamed zip).

PROBLEM: "D3: rend_Init failed"
FIX:     EGL context must be current BEFORE rend_Init is called.
         OffscreenGL::Init() must run before D3TextTestHarness::Initialize().
         Verify the GTest SetUpTestSuite order in test_main.cpp.

PROBLEM: Framebuffer is entirely black (test_hud_green fails)
FIX:     grtext_Stop() must be called before glReadPixels (it flushes batches).
         Verify EndFrame() calls grtext_Stop() before rend_EndFrame().

PROBLEM: "SDL_VIDEODRIVER" causes ddio_Init crash
FIX:     SDL_VIDEODRIVER=offscreen must be set before ddio_Init is called.
         It is set as a ctest env var and must also be set for direct runs.

PROBLEM: Build fails because MesaOpenGL.cpp references missing SDL symbols
FIX:     You did not replace all SDL calls. Re-audit the file you cloned.
         Grep for any remaining SDL references:
           grep -n "SDL_" renderer/MesaOpenGL.cpp

PROBLEM: Duplicate symbol linker errors for renderer functions
FIX:     Both HardwareOpenGL.cpp (or HardwareSetup.cpp) AND MesaOpenGL.cpp
         are being compiled. Check renderer/CMakeLists.txt -- only ONE
         should be compiled depending on BUILD_TESTING flag.


================================================================================
INITIALIZATION ORDER (DO NOT CHANGE)
================================================================================

This order is mandatory. Changing it will cause crashes or silent failures.

  1.  OffscreenGL::Init()          -- EGL pbuffer + llvmpipe context current
  2.  mem_Init()                   -- D3 memory system
  3.  ddio_Init()                  -- D3 device I/O (needs SDL_VIDEODRIVER=offscreen)
  4.  cfile_Init()                 -- D3 file/HOG system
  5.  cfile_AddSearchPath(base)    -- Point at Descent3 data directory
  6.  bm_Init()                    -- D3 bitmap/texture system
  7.  g3_Init()    [if it exists]  -- D3 3D math/projection (verify in Step 2)
  8.  rend_Init()                  -- D3 renderer (attaches to EGL context from 1)
  9.  grtext_Init()                -- D3 font system
  10. grtext_LoadFont("lohud.fnt") -- Load HUD font from d3.hog


================================================================================
KEY FACTS TO KEEP IN MIND
================================================================================

- SDL3 uses SDL_GL_DestroyContext, NOT SDL_GL_DeleteContext (deleted in SDL3).
- The EGL context is created in OffscreenGL::Init(), NOT in MesaOpenGL.cpp.
  MesaOpenGL.cpp attaches to the already-current context via rend_Init().
  Do not create a second EGL context inside MesaOpenGL.cpp.
- glReadPixels returns pixels with Y=0 at the BOTTOM (GL convention).
  Flip vertically before writing PNG (Y=0 at top is PNG convention).
- grtext batches draw calls. Always call grtext_Stop() before glReadPixels.
- The overlays/dbus directory in the repo is a vcpkg overlay port.
  It is needed for cross-compilation and should not be removed.
- Tests require actual Descent 3 game data (d3.hog). This file is NOT in the
  repo and must be provided by the user from a legitimate copy of the game.
- The tests/ directory may already have content. Check before overwriting.
